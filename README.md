# Console Racing Game

A simple console-based racing simulation implemented in both **C#** and **Python**.

The project was created as part of university coursework to practice object-oriented programming, application flow, collections and basic game logic.

## Project Overview

The application simulates a basic car race using several objects responsible for different parts of the race flow.

The project includes concepts such as:

- Cars participating in the race
- Track and race structure
- Lap timing
- Race flow and result calculation
- Basic podium/result output
- Object-oriented organization of the application
